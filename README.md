# LIMINAL ATLAS — 境界世界の記録

六つのオリジナルな境界世界を歩く、ブラウザ向けの3D探索作品。

「不気味・神秘的・幻想的」を、色替えだけでなく建築、奥行き、スケール、明かりで描き分けています。人物の追跡、突然の大音量、強い点滅はありません。

## 六つの世界

| 世界 | 空間 |
| --- | --- |
| 彼岸の旅館 / The Inn Between | 木の廊下、障子、畳の客室、誰も迎えに来ない灯り |
| 星祈りの聖堂 / The Astral Chapel | 高い石柱、アーチ、浮遊する月、星が漂う祭壇 |
| 紅月の回廊 / The Vermilion Moon | 朱の柱、翡翠の重ね屋根、石庭、異様に大きい紅月 |
| 第零航宙船 / Vessel Zero | 観測窓、発光する床の導線、回転するコア、外の惑星 |
| 眠らないコロニー / The Borrowed Sun | 人工ドーム、集合住宅、空中通路、暮れない人工太陽 |
| 巨樹の胎内 / The Dreaming Root | 巨木、根のアーチ、大きな光る菌傘、浮遊する胞子 |

各世界は有限の探索空間です。戦闘やクリア条件のあるゲームではなく、静かに歩いて雰囲気を楽しむ作品です。建築、テクスチャ、配置、シェーダーはコードで生成しています。

## 操作

- 世界のカードを選ぶとプレビュー。「この世界へ入る」で探索開始
- PC: W/A/S/D または矢印で歩く。ドラッグで見回す。クリックすると、対応環境ではマウスを固定
- Shift: 速く歩く / R: 入口に戻る / H: UI表示切替 / Esc: 設定を閉じる、または世界選択へ
- スマートフォン: 左パッドで移動、右側をスワイプして視点操作。移動と見回しは同時操作可能
- 「知覚 / 設定」: 演出の強さ、色収差、ゆらぎ、残像、動きを抑える、環境音、描画品質
- 環境音は常にオフから開始。ブラウザ内で合成するため音声ファイルの取得は不要

### 快適に遊ぶために

視覚効果はフィクションの演出です。体調や知覚を再現・診断するものではありません。違和感があれば効果を0にする、動きを抑える、または探索を休んでください。OSの「視差効果を減らす」設定を初回に尊重します。デバイスに負荷がかかる場合は「軽量」を選んでください。

## ローカル実行

Node.js 22.12以降が必要です。

```sh
npm ci
npm run dev
```

表示された localhost URLを開きます。WebGL 2に対応する最近のChrome、Edge、Firefox、Safariを想定しています。`index.html`の直接ダブルクリック（file://）ではなくHTTPサーバーを使ってください。

```sh
npm test            # 決定的な生成、入口、衝突、境界、破棄、保存失敗の検証
npm run build      # dist/ に配布可能な静的ファイルを生成
npm run preview    # 生成した本番ビルドの確認
npx playwright install chromium
npm run test:e2e    # 6世界、マウス、タッチ、GPUメモリ、設定のブラウザ検証
```

システムのChromiumを使う場合は`CHROMIUM_PATH=/path/to/chromium npm run test:e2e`。ブラウザを起動できないサンドボックスでは、単体テストのみを「ブラウザ検証済み」と扱わないでください。

## GitHub Pages

```sh
npm run build:pages
```

`docs/`に相対パスで実行できる静的ビルドを生成します。GitHub Pagesの公開元は **Deploy from a branch → main → /docs**。ソース更新後は同じコマンドで`docs/`を更新してコミットしてください。GitHub Actionsは単体・ブラウザテスト、依存関係監査、コミットした配布ファイルの一致を検証します。自動で権限や認証情報を作成しません。

別の静的HTTPホストには`dist/`または`docs/`の内容をそのまま配布できます。独自API、バックエンド、CDNアセット、APIキーは不要です。

## 実装とプライバシー

- Three.js + Vite。外部画像・モデル・音源・フォントなし
- 重複する建築部品はInstancedMeshでまとめ、同時に保持する世界は一つだけ
- ワールド切替でジオメトリ、マテリアル、テクスチャ、インスタンスを破棄
- 固定の乱数シード、壁沿いのスライド衝突、小刻みな衝突判定、正常な入口
- 高DPIの上限と総描画ピクセル数の制限。タッチ端末は軽量から開始
- 設定は端末のlocalStorageのみ。ストレージが拒否されても動作
- 解析、広告、追跡、アカウント、ユーザーデータ送信なし
- `window.liminalAtlas.snapshot()` はテスト用の読み取り専用状態スナップショット。ネットワークへ送信しません
